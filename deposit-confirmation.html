Konfirmasi Deposit

Formulir khusus member MPS untuk membantu admin memeriksa akun IB dan administrasi program rebate.

Perlu diketahui: Formulir ini bukan syarat untuk bergabung dengan komunitas MPS. Isi hanya jika kamu ingin mengajukan verifikasi akun untuk program IB/rebate MPS. Status pengajuan awal adalah menunggu pemeriksaan admin.
Nominal akan otomatis menggunakan titik pemisah ribuan. Contoh: 1.000.000.
Pastikan bukti menunjukkan transaksi deposit yang relevan. Tutupi informasi pribadi yang tidak diperlukan sebelum mengunggah.

Jangan pernah mengunggah password MT5, password investor, OTP, data kartu, atau informasi login rahasia. Pengiriman hanya akan aktif setelah koneksi penyimpanan resmi dipasang.
